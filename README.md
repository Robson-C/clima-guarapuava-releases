# Clima Guarapuava para Android

Canal de versões do aplicativo pessoal Clima Guarapuava.
Este repositório contém os APKs assinados e o manifesto de atualização;
o projeto e a chave de assinatura são mantidos fora deste repositório.

## Instalação inicial

Baixe o APK na página de Releases e instale por cima da versão anterior.
Na versão 0.3.0 ou superior, abra o app e toque em **Permitir atualizações**.
Permita também as notificações para receber solicitações de confirmação.
Depois, o próprio aplicativo consulta e baixa versões novas ao abrir e
periodicamente. O Android pode pedir confirmação para concluir a instalação.

O widget 4×3 mostra as próximas seis horas completas em Guarapuava/PR:
às 20:05, começa às 21h. Dados meteorológicos: **CPTEC/INPE**.
